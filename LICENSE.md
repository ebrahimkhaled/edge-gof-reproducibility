# Licences

This archive carries two licences, because it holds two kinds of material.

**Code — GPL-3.** Everything under `code/`, which is the study's R and Python source. GPL-3 is chosen to
match the `ebrahim.gof` package the code accompanies and calls. Full text:
<https://www.gnu.org/licenses/gpl-3.0.txt>.

**Everything else — CC BY 4.0.** The declarations, the deposited results and the manuscript source and
figures under `declarations/`, `results/` and `manuscript/`. Full text:
<https://creativecommons.org/licenses/by/4.0/legalcode>.

Both licences ask only that the work is attributed. Cite the archive by its DOI, and the paper by its
own.

The Diabetes 130-US Hospitals data analysed in the paper are not redistributed here. They belong to the
UCI Machine Learning Repository (DOI 10.24432/C5230J) and are used under that repository's terms. The
README says where to download the file and where to put it, and gives its sha256 so that a reader can
confirm they hold the same file the study used.
